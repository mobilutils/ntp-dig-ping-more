NTP DIG PING MORE — Professional Network Diagnostics Toolkit

A comprehensive Android network troubleshooting suite for IT administrators, developers, and network professionals. Get real-time insights into your network infrastructure from anywhere.

KEY FEATURES:
• NTP Check — Verify time server reachability with precise clock offset calculation
• DNS (DIG) Test — Query custom DNS servers, detect NXDOMAIN, trace CNAME chains
• Ping — ICMP echo testing with configurable packet count and timeout
• Traceroute — TTL-probing to identify network hops and latency bottlenecks
• Port Scanner — TCP/UDP port scanning with configurable ranges and per-port timeouts
• LAN Scanner — Subnet device discovery via concurrent ping sweeps and ARP parsing
• Google Time Sync — HTTP-based time sync with RTT and clock offset calculation
• HTTPS Cert Inspector — Full TLS certificate chain analysis, expiry warnings, fingerprints
• Bulk Actions — Execute batch commands from JSON configs (headless via ADB automation)

PROFESSIONAL-GRADE TOOLS:
• Dual-stack IPv4/IPv6 support
• Global configurable timeouts per operation
• Persistent history for all tools (up to 10 entries each)
• Proxy PAC script evaluation for corporate environments
• MDM/EMM managed configuration support (Intune, Jamf, Workspace ONE, etc.)
• 365+ unit tests ensure reliability and accuracy

HEADLESS AUTOMATION:
Bulk Actions enables fully automated network testing via ADB:
• Run batch command sequences from JSON configs
• Generate CSV or text output files
• No user interaction required — perfect for CI/CD pipelines
• Supports Android 8.0+ (API 26+)

TECHNICAL SPECS:
• Built with Kotlin, Jetpack Compose, Material 3
• Uses Apache Commons Net (NTP), dnsjava (DNS), QuickJS (PAC)
• Min SDK: 26 | Target SDK: 37
